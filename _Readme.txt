Unity C# Portfolio Showcase

A collection of modular, production-ready systems built in Unity, demonstrating clean architecture, procedural animation, and backend integration.

1. Startup & Network System
Purpose: Manages the game's bootstrap sequence.

Key Features: Internet verification, UGS anonymous authentication, NTP network time synchronization, and safe asynchronous scene loading.

2. Advanced Touch Input Manager
Purpose: Centralized touch and gesture handling.

Key Features: Singleton-based architecture, dynamic state machine (Tap, Hold, Swipe, Double-Tap), and an event-driven design using Unity's Input System.

3. Procedural Physics & Ragdoll Locomotion ("Silly Frog Physics")
Purpose: Physics-driven character movement and procedural animation.

Key Features: Custom 2-bone IK leg solver, predictive landing raycasts, slope body alignment, interactive gripping, and timing-based jump boosts.
